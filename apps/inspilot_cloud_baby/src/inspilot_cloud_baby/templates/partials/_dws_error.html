获取流程失败

输入：{{ workflow_id }}

{{ error }}

常见原因：

  • API 权限不足 — DWS OAuth Token 只能访问你是审批人或发起人的流程。你在钉钉 App 能看到的流程不一定能通过 API 访问
  • 输入了工单号而非实例 ID — 如果是纯数字（如 202602031722000061965），请确认它是否为工单号。尝试从钉钉 OA 审批详情页 URL 中获取 processInstanceId
  • 流程 ID 不存在或已删除
  • DWS CLI 未登录 — 运行 dws auth login

💡 如何获取审批实例 ID：

  1. 打开钉钉 → 工作台 → OA 审批 → 找到目标审批单
  2. 点击进入审批详情页
  3. 查看浏览器地址栏 URL，找到 processInstanceId=xxx 参数
  4. 复制 xxx 的值（通常类似 Uh6LpPqiSEiailbBafHsGw00861752...）
