{# ---- Enterprise app mode guide ---- #}
🏢 企业内部应用模式（推荐 — 可访问全部审批）

为什么要配置企业内部应用？

  • 个人 OAuth 模式（dws auth login）只能访问你作为审批人或发起人的流程
  • 被抄送的流程、已流转到其他节点的流程均无法通过个人 OAuth 访问
  • 企业内部应用模式使用 AppKey/AppSecret 获取 access_token，可访问全部审批实例

📋 配置企业内部应用

#步骤操作
1 登录钉钉开放平台 访问 open-dev.dingtalk.com，用企业管理员账号登录
2 创建企业内部应用 应用开发 → 企业内部开发 → 创建应用 → 填写应用名称（如「InsPilot 审批导入」）
3 获取 AppKey 和 AppSecret 进入应用 → 凭证与基础信息 → 复制 AppKey 和 AppSecret
4 申请 API 权限 权限管理 → 搜索并开通：
审批 — 获取审批实例详情 / 获取审批实例ID列表
5 发布应用 版本管理与发布 → 确认发布
6 配置 InsPilot 在 .env 文件中写入： 
BUSINESS_ROBOT_DWS_CLIENT_ID=你的AppKey
BUSINESS_ROBOT_DWS_CLIENT_SECRET=你的AppSecret
7 重启服务验证 重启 InsPilot 后，点击上方「检测连接」按钮确认状态
