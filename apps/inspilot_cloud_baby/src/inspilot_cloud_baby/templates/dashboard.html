📖 使用说明

  • 资料投喂 — 将业务资料（条款 PDF、费率表、操作指南、项目方案等）录入系统。支持粘贴文本或上传文件，系统自动识别资料类型和敏感级别，人工确认后入库。
  • 知识管理 — 查看所有已录入的知识条目。支持按项目、状态、敏感级别筛选。可对条目执行审核通过、归档、删除等操作。
  • 项目管理 — 管理项目及其可见范围（公司可见 / 项目成员 / 受限）。项目是知识条目的归属容器。
  • DWS 导入 — 输入钉钉流程 ID 或工单号，从 DWS（钉钉工作流）导入历史流程数据。

🚀 快速开始

  • 第一步：前往 项目管理 创建至少一个项目，作为资料的归属范围。
  • 第二步：前往 资料投喂 粘贴或上传资料文本，系统自动识别后确认入库。
  • 第三步：前往 知识管理 审核新录入的资料，确认后状态变为「已生效」，可被检索使用。

⚙️ 系统架构

  • 知识分层：事实层（审核通过的结构化数据）、候选层（待审核的新录入数据）、参考层（原始非结构化资料）
  • 敏感级别：公开摘要（公司可见的汇总信息）、项目受限（仅项目成员可见）、敏感（含 PII，需授权查看）
  • 资料类型：费率表、操作指南、技术方案、项目笔记 — 系统根据内容自动识别
  • 状态流转：草稿 → 待审核 → 已生效 → 已归档（冲突状态用于标记版本冲突）
