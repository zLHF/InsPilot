# InsPilot 云小宝 Stitch 原型优化规格

日期：2026-06-09
来源：Stitch 项目 `InsPilot Cloud Assistant`、本地 PRD `2026-06-06-inspilot-cloud-baby-prd-v2.4.md`

## 1. 目标

将现有 Stitch 移动端原型完善为可评审、可点击、可继续开发的 InsPilot 云小宝 Alpha 产品原型。原型优先服务市场、运营和业务线用户在钉钉移动容器中的日常使用，覆盖“表达问题/需求 -> 机器人追问补全 -> 结构化输出 -> 钉钉流转/记录追溯”的主路径。

## 2. 设计方向

- 保留 Stitch 设计系统：Manrope + Inter + JetBrains Mono、专业蓝、效率青、候选琥珀、参考灰。
- 视觉气质保持企业级、可信、信息密度高，但移动端首屏必须能快速判断“我该问什么、现在处理到哪一步”。
- 页面采用 390px 移动端主画布，兼容桌面浏览器居中预览。
- 所有关键结论需要体现来源、置信度、权限状态或待确认状态，避免把 AI 推断表现成事实。

## 3. 原型范围

### 会话主页

- 顶部展示当前身份、入口环境、算力/安全状态。
- 首屏提供四个主要场景入口：历史知识查询、项目变更、需求提炼、系统问题。
- 支持多模态输入入口：文字、语音、截图、文件、录屏。
- 展示一次完整业务会话：用户输入、机器人识别意图、追问进度、附件解析状态、结构化输出预览。
- 输出预览应区分事实层、候选层、参考层，并展示可追溯来源。

### 记录页

- 支持搜索项目名、内容关键字和状态。
- 按处理状态展示记录：待补充、待确认、已提交、已解决。
- 每条记录展示场景类型、项目、下游流转状态、更新时间、输出版本。
- 支持查看结构化输出和继续补充材料。

### 我的页

- 展示角色、项目权限、安全状态、知识贡献。
- 增加 PII 脱敏、数据权限申请、知识库投喂入口。
- 明确“项目公开不等于资料全部公开”，将项目开放级别和知识敏感级别可视化。

### Flow/状态

- 用横向步骤表达主链路：输入 -> 识别 -> 追问 -> 输出 -> 提交 -> 回传。
- 显示并发/版本锁、退回补充、异步多模态处理状态。

## 4. 关键交互

- 底部 Tab 在“对话、记录、我的”之间切换，不刷新页面。
- 场景 chip 可切换当前会话模式，输入占位文案随模式变化。
- 点击多模态按钮打开上传面板，展示图片、语音、文件、录屏四类入口及配额提示。
- 点击“生成结构化输出”展示输出抽屉，支持 Markdown/JSON 视图切换。
- 点击“提交钉钉流程”将状态改为“已提交”，记录页同步显示流转状态。
- PII 开关可在“脱敏视图/授权查看”之间切换，授权查看需要显示审计提示。

## 5. 验收标准

- 原型可在本地浏览器打开并完成主要点击路径。
- 390px 移动端无文本重叠、底部输入栏不遮挡核心内容。
- 三个 Tab 均有完整内容，不是静态空壳。
- 页面中显式体现 PRD V2.4 的权限、敏感级别、结构化输出、钉钉流转和多模态配额要求。
- 自动化测试覆盖关键 DOM、Tab 切换、输出抽屉和提交状态。
